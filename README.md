


# Driver Drowsiness Detection System

## Overview
A real-time driver drowsiness detection system that monitors eye movements using computer vision and alerts the driver when signs of drowsiness are detected.

## Technologies Used
- Python
- OpenCV
- Dlib
- NumPy

## Features
- Real-time face detection
- Eye aspect ratio calculation
- Drowsiness alert system
- Audio warning notification

## How to Run
1. Install dependencies
   pip install -r requirements.txt

2. Run the application
   python main.py
